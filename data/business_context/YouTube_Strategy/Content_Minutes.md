# Content_Minutes.md

## Purpose
To provide the content minutes framework.

## Core Philosophy
**To build trust, people need to watch a certain number of minutes.**

- Each minute = One block of trust
- Different offers need different blocks
- Bingeability stacks blocks quickly
- YouTube gives more blocks per rep

## Principles

### 1. Content Minutes
```
4 blocks → Email lead magnet
12 blocks → $97 product
400 blocks → $10,000 product

The only way blocks count is if they actually watch it.
```

### 2. The Bingeability Factor
- If you can get them to watch multiple pieces in one session
- Blocks stack faster
- Series create bingability
- Thumbnail covers help

### 3. YouTube vs. Shorts
```
YouTube: 25-min video, 8-10 min AVD
  → 8-10 blocks per rep

Shorts: 60-sec video, 30-sec AVD
  → 0.5 blocks per rep

It takes 20 shorts to equal one long-form video in trust.
```

## Process

### Content Minutes Strategy:
```
1. Define your offer
2. Map the blocks needed to convert
3. Create content that delivers blocks
4. Use long-form for high block count
5. Use shorts for bingability
6. Stack blocks through series
```

## Decision Framework

```
What Content Format Should I Use?
  │
  ├─ Need high trust? → YouTube (more blocks)
  ├─ Need quick trust? → Shorts (less blocks)
  ├─ Need bingability? → Series (stack blocks)
  └─ Need conversion? → Match blocks to offer
```

## Rules

**Always:**
- Map blocks to offer
- Use long-form for high-value offers
- Create bingability
- Stack blocks through series

**Never:**
- Underestimate the blocks needed
- Think shorts build trust like long-form
- Forget about bingability
- Ignore the block math

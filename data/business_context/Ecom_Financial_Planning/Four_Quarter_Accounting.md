# Four_Quarter_Accounting.md

## Purpose
To provide a framework for simplified P&L analysis.

## Core Philosophy
**Every P&L can be broken into four categories.**

- Cost of Delivery (COGS + variable expenses)
- CAC (marketing expense)
- OPEX (fixed costs)
- Profit

## Principles

### 1. The Four Categories
```
Category 1: Cost of Delivery
  ├─ Cost of goods
  ├─ Shipping expense
  └─ Variable expenses

Category 2: CAC (Marketing)
  ├─ Pure media dollars
  └─ Variable marketing expense

Category 3: OPEX (Fixed Costs)
  ├─ Rent
  ├─ Labor
  ├─ Software
  └─ Marketing contractors/agencies (if fixed)

Category 4: Profit
  └─ What's left
```

### 2. Industry Benchmarks
| Category | Ecom Average | Ideal |
|----------|--------------|-------|
| Cost of Delivery | 30-40% | 30-40% |
| CAC | 25-50% | Varies by business model |
| OPEX | 10-15% | 10-12% |
| Profit | 10-20% | 15-20% |

### 3. Business Model Matters
- Ridge Wallets: 50% marketing, low opex, high gross margin
- High LTV business: Marketing % of revenue declines over time
- Hard goods: 40-50% marketing, low opex
- Service: 0% marketing (negative CAC), higher opex

## Process

### Four Quarter Accounting:
```
1. Ask accountant to build four-quarter view
2. Show each category every month
3. See where profit is going
4. Ask: "Which of these can I create leverage against?"
5. Focus on the problem category
6. Repeat monthly
```

## Decision Framework

```
Where Is My Profit Going?
  │
  ├─ Cost of Delivery too high?
  │   ├─ Fix: Better shipping terms, lower COGS
  │   └─ Goal: 30-40% of revenue
  │
  ├─ CAC too high?
  │   ├─ Fix: Better creative, better targeting
  │   └─ Goal: Depends on LTV and business model
  │
  ├─ OPEX too high?
  │   ├─ Fix: Lean team, AI automation
  │   └─ Goal: 10-12% of revenue
  │
  └─ Profit too low?
      └─ Address the largest problem category
```

## Rules

**Always:**
- Break P&L into four categories
- Track monthly
- Identify the problem category
- Focus on fixing it

**Never:**
- Get lost in line-item complexity
- Ignore the category breakdown
- Think all categories are equal
- Forget business model differences

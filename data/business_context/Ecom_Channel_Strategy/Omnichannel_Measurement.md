# Omnichannel_Measurement.md

## Purpose
To provide frameworks for measuring omnichannel performance.

## Core Philosophy
**Media exists to drive your business growth, not just your .com growth.**

- As you expand distribution, your measurement must broaden
- Meta dollars drive Amazon and retail, not just .com
- YouTube drives as much value on Amazon as .com
- The best brands measure across all channels

## Principles

### 1. The Distribution-Measurement Gap
```
If you're only measuring .com:
  │
  ├─ Amazon grows → .com efficiency appears to decline
  ├─ Retail grows → .com efficiency appears to decline
  └─ You pull back → Whole engine stalls
```

### 2. The Value by Channel
- Meta: 80% of value on .com, 20% on Amazon
- YouTube: 50% on .com, 50% on Amazon
- Higher funnel = More value on larger channels
- CTV: Even more value on Amazon/retail

### 3. The 2026 Playbook
```
Top of Funnel: YouTube, TikTok Shop (neutral margin)
  │
  ├─ Drives awareness and demand
  └─ Value realized in other channels

Value Realization: Limited edition, high AOV
  │
  └─ True fans, high margin

Volume Movement: Amazon, .com
  │
  └─ Core SKUs, volume scale
```

### 4. Incrementality Testing
- Geo hold-out tests
- Isolate new channels
- Measure net new demand
- Understand true effect

## Process

### Omnichannel Measurement:
```
1. Measure media effect on .com
2. Measure media effect on Amazon (incrementality study)
3. Measure media effect on retail (if applicable)
4. Understand the blended effect
5. Optimize for total business, not .com
6. Don't pull back when .com efficiency declines
```

## Decision Framework

```
How Should I Measure This Channel?
  │
  ├─ Meta → 80% .com, 20% Amazon
  │
  ├─ YouTube → 50% .com, 50% Amazon
  │
  ├─ CTV → Mostly Amazon/retail
  │
  └─ TikTok Shop → Treat as separate ecosystem
```

## Rules

**Always:**
- Measure across all channels
- Use incrementality studies
- Optimize for total business
- Don't let .com efficiency alone drive decisions

**Never:**
- Measure only .com
- Pull back when .com efficiency declines
- Ignore Amazon or retail halo
- Think channels operate in silos

# International_Strategy.md

## Purpose
To provide a framework for international expansion.

## Core Philosophy
**Operational simplicity over demand. Go to markets that actually make money.**

- Section 321 (duty-free cross-border shipping) is gone
- Need localized warehouses
- Start with English-speaking markets
- Skip hard markets until you're massive

## Principles

**1. Section 321 Is Gone**
- The Trump administration banned it
- Timu and Shein built their models on it
- Gone for various reasons
- You need localized warehouses now

**2. The Market Order**
```
1. UK (First)
   ├─ Speaks English
   ├─ Has money
   └─ Cheap shipping

2. Canada (Second)
   └─ Same as UK

3. EU (Third)
   ├─ Harder (multiple languages)
   ├─ 60% English penetration for .com shopping
   └─ Need localization

4. Australia (Fourth)
   └─ Serve from Hong Kong (air shipping)
```

**3. Why Localized Warehouses**
- Payment processing rates: 0.5% (UK) vs 2.5% (US)
- Shipping: $4 (UK) vs $5 (US) minimum
- Next-day shipping possible
- Different price points possible

**4. Skip Hard Markets**
- India: Too hard until $1B+ scale
- France/Germany/Spain/Italy: Need localization
- Don't go where you can't make money
- If you're not making money, shut it off

## Process

**International Expansion:**
```
1. Start with UK warehouse
2. Set up local Shopify store
3. Local payment processing
4. Local shipping
5. Test with limited SKUs
6. Scale if profitable
7. Add Canada, then EU, then Australia
8. Skip hard markets
```

## Decision Framework

```
Should I Enter This Market?
  │
  ├─ Do they speak English?
  │   ├─ YES → Easier
  │   └─ NO → Harder
  │
  ├─ Is shipping cheap?
  │   ├─ YES → Good
  │   └─ NO → Probably not
  │
  ├─ Are payment processing rates low?
  │   ├─ YES → Good
  │   └─ NO → Eat margin
  │
  └─ Will it be more than another California?
      ├─ YES → Consider
      └─ NO → Skip
```

## Rules

**Always:**
- Start with UK
- Localize warehouses
- Use local Shopify stores
- Ship next-day locally

**Never:**
- Ship cross-border from US
- Skip localized warehouses
- Enter hard markets early
- Lose money on international shipping

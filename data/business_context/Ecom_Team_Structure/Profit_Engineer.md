# Profit_Engineer.md

## Purpose
To provide frameworks for the modern marketing team structure.

## Core Philosophy
**The future of marketing is one person who does it all.**

- Media buying is not a full-time job for one brand
- Creative strategy is not a full-time job for one brand
- AI tools make generalists more powerful than specialists
- The profit engineer is the evolution of the full-stack engineer

## Principles

### 1. The Old Team Structure
```
Head of Growth
  │
  ├─ Media Buyer (Meta)
  ├─ Media Buyer (Google)
  ├─ Creative Strategist
  └─ Retention Strategist
```

### 2. The New Team Structure
```
Profit Engineer
  │
  ├─ Forecasts the business
  ├─ Manages the media account
  ├─ Defines the creative
  ├─ Uploads the creative
  ├─ Designs the email calendar
  └─ Delivers the outcome
```

### 3. Why This Works
- AI tools handle the research and output
- One person can do what four used to do
- No message degradation between silos
- Direct connection between goal and accountability

### 4. The Key Skill
- Connecting the dots between expectation and outcome
- Not just executing tasks
- Owning the result
- Being accountable for the contribution margin

## Process

### Building a Profit Engineer Team:
```
1. Identify the key marketing functions
2. Consolidate into one role
3. Equip with AI tools
4. Set clear expectations
5. Hold accountable for contribution margin
6. Replace siloed team with profit engineers
7. Scale by adding more profit engineers
```

## Decision Framework

```
What Team Structure Do I Need?
  │
  ├─ Is this a full-time job for one brand?
  │   ├─ Media buying → NO (with AI)
  │   ├─ Creative strategy → NO (with AI)
  │   └─ Retention → NO (with AI)
  │
  ├─ Can one person do it all?
  │   ├─ YES → Profit engineer
  │   └─ NO → Need specialist
  │
  └─ What's the goal?
      └─ One accountable person
```

## Rules

**Always:**
- Consolidate marketing roles
- Use AI tools for leverage
- Hold one person accountable
- Focus on contribution margin

**Never:**
- Have siloed marketing functions
- Let message degrade across teams
- Have no single accountable person
- Ignore AI productivity gains

# Channel_Allocation.md

## Purpose
To provide a framework for marketing channel allocation.

## Core Philosophy
**Find the perfect level of spend on every channel.**

- Meta is still the king
- YouTube has gotten better
- Diversify across channels
- The next best dollar framework

## Principles

**1. The Channel Breakdown**
| Channel | % of Spend | Notes |
|---------|------------|-------|
| Meta | 50-75% | King of advertising |
| Google/YouTube | 20% | Search 5%, YouTube 15% |
| Influencer | 10% | YouTube sponsorships |
| Tertiary | 20% | Snap, TikTok, Reddit, X, AppLoving, Pinterest |

**2. The Next Best Dollar Framework**
- Every channel has a perfect level of spend
- Spend meta until the next best dollar is better spent elsewhere
- Figure out the perfect level of spend on every channel
- It always changes (messy mix)

**3. Google Shopping Is Not Incremental**
- Most brands overspend on branded search
- Should be sub-1% of marketing spend
- Shopping is not very incremental
- Non-branded has some world

**4. YouTube Has Gotten Better**
- They've united more of the Google ad ecosystem
- YouTube Shorts is underpriced
- Few people spend money on YouTube Shorts
- Good for starting

## Process

**Channel Allocation:**
```
1. Start with meta (it works)
2. Add YouTube (15% of spend)
3. Add Google search (5% of spend, branded only)
4. Test tertiary channels ($1-10K/day)
5. Use incrementality testing to validate
6. Shift budget based on performance
7. Repeat
```

## Decision Framework

```
Where to Spend the Next Dollar?
  │
  ├─ Is meta still profitable?
  │   ├─ YES → Spend more on meta
  │   └─ NO → Consider next channel
  │
  ├─ Is YouTube profitable?
  │   ├─ YES → Allocate more
  │   └─ NO → Test or move on
  │
  ├─ Are tertiary channels working?
  │   ├─ YES → Scale gradually
  │   └─ NO → Cut
  │
  └─ Am I measuring incrementality?
      ├─ YES → Optimize
      └─ NO → Need measurement first
```

## Rules

**Always:**
- Start with meta
- Add YouTube (Shorts underpriced)
- Diversify across channels
- Use incrementality testing

**Never:**
- Overspend on branded search
- Ignore YouTube
- Put all money in one channel
- Skip incrementality testing

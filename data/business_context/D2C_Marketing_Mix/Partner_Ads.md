# Partner_Ads.md

## Purpose
To provide a framework for partner/whitelisted ads.

## Core Philosophy
**Partner ads are working better for everyone.**

- Single handle helps
- Meta is prioritizing partner ads
- Two handles = Better signal
- AI algorithm prefers it

## Principles

**1. Partner Ads Work Better**
- Every brand I talk to says the same
- Meta is pushing it aggressively
- They get better signal with two handles
- Better targeting = Better performance

**2. The Handle Doesn't Matter**
- Famous accounts don't perform better
- Followers are completely irrelevant
- You can run from any account
- Owned accounts work just as well

**3. Structure**
```
Partner Ad Setup:
  ├─ Creator posts content
  ├─ Brand runs ads from creator's handle
  ├─ Flat fee (not percentage of revenue)
  └─ No complicated math
```

**4. How to Source Partners**
- Gifting (Refunnel)
- Find people who make good content
- Bring them into UGC funnel
- Pay them for content + whitelisting

## Process

**Partner Ad Workflow:**
```
1. Gift product (Refunnel)
2. Identify who makes good content
3. Bring into UGC roster (30-50 people)
4. Pay flat fee for content
5. Get whitelisting access
6. Run ads from their handle
7. Scale winners
```

## Decision Framework

```
Should I Run Partner Ads?
  │
  ├─ Can I get whitelisting access?
  │   ├─ YES → Run them
  │   └─ NO → Need access first
  │
  ├─ Do I have a roster of partners?
  │   ├─ YES → Scale
  │   └─ NO → Build roster
  │
  ├─ Am I using gifting to find people?
  │   ├─ YES → Good
  │   └─ NO → Start gifting
  │
  └─ Is it flat fee or percentage?
      ├─ Flat → Good
      └─ Percentage → Complicated
```

## Rules

**Always:**
- Run partner ads
- Build a roster of partners
- Use gifting to find creators
- Keep it simple (flat fee)

**Never:**
- Complicate with percentage math
- Think the handle matters
- Underestimate partner ads
- Skip gifting

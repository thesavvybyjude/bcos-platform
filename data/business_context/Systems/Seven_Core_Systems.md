# Seven_Core_Systems.md

## Purpose
To provide a complete framework for the core systems every business needs.

## Core Philosophy
**If you can't walk away for 30 days and come back stronger, you don't have a business—you have a high-paying job.**

- 98% of founders live in "founder prison"
- 21 systems across 7 core areas
- Systems = Repeatable processes others can execute
- Document everything, own everything

## Principles

### 1. The Seven Core Areas
```
1. Awareness → How people find you
2. Sales → Converting prospects to customers
3. Marketing → Nurturing and building trust
4. Onboarding → Bringing customers in smoothly
5. Finance → Cash flow, accounting, collections
6. Delivery → Fulfilling on your promise
7. Renewal → Keeping customers and driving referrals
```

### 2. The 21 Systems
- 3 systems per core area
- 21 systems total
- Each system documented in detail
- Each system has an owner

### 3. The Founder Prison
- 72% of founders dealing with mental health issues
- Constant Slack checking
- Team needs direction constantly
- Business collapses without founder
- Systems are the escape route

## Process

### Systems Audit Framework:
```
1. Map your business from awareness to renewal
2. Identify bottlenecks in each area
3. Create 3 systems per area (21 total)
4. Document each system
5. Assign a system owner
6. Train the owner
7. Update and improve continuously
```

## Decision Tree

```
Which System Should I Build First?
  │
  ├─ Where is the biggest bottleneck?
  │   ├─ Awareness → Need content system
  │   ├─ Sales → Need sales process
  │   ├─ Delivery → Need fulfillment system
  │   └─ Renewal → Need retention system
  │
  ├─ What frustrates me most?
  │   └─ Build that system first
  │
  ├─ What takes the most time?
  │   └─ Build that system first
  │
  └─ What would free me the most?
      └─ Build that system first
```

## Rules

**Always:**
- Document everything
- Assign ownership
- Train system owners
- Update continuously

**Never:**
- Keep processes in your head
- Have no owner
- Let systems get stale
- Be the only one who knows

# SOP_Creation.md

## Purpose
To provide frameworks for creating Standard Operating Procedures (SOPs).

## Core Philosophy
**Systems are the foundation of freedom. AI eats systems for breakfast.**

- Document once, use forever
- Loom AI creates SOPs in one click
- Documentation = Scalability
- Without documentation, you're building a hobby

## Principles

### 1. Use Loom for SOP Creation
```
1. Film yourself completing a task (5-10 min)
2. Upload to Loom
3. Click "Loom AI"
4. Say "Create SOP"
5. Bam - Done
```

### 2. Systems Must Be Repeatable
- Anyone should be able to do it
- As good if not better than you
- Step-by-step instructions
- Clear expectations

### 3. Document the Details
- What we do and don't do
- What we say and don't say
- How we share screen
- How we color grade
- Sound quality standards

## Process

### SOP Creation Workflow:
```
1. Identify a task you do repeatedly
2. Film yourself doing it (Loom)
3. Use Loom AI to create SOP
4. Review and refine the SOP
5. Add to Notion/Google Docs
6. Train team on SOP
7. Update with feedback
```

## Decision Framework

```
What Should I Document?
  │
  ├─ Do I say this more than once?
  │   ├─ YES → Document it
  │   └─ NO → Probably not needed
  │
  ├─ Does this get done by others?
  │   ├─ YES → Document it
  │   └─ NO → Can stay in head
  │
  ├─ Is this critical to operations?
  │   ├─ YES → Document it
  │   └─ NO → Low priority
  │
  └─ Will I forget this?
      ├─ YES → Document it
      └─ NO → Maybe not
```

## Rules

**Always:**
- Document everything said twice
- Use Loom AI for SOP creation
- Assign ownership
- Update regularly

**Never:**
- Keep processes in your head
- Repeat yourself without documenting
- Have no SOP for critical tasks
- Let SOPs get outdated

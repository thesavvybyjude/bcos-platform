# Contribution_Margin.md

## Purpose
To provide a framework for contribution margin analysis.

## Core Philosophy
**Contribution margin is the closest proxy to cash flow you can track daily.**

- Fixed costs create counter-signals
- Contribution margin minus OPEX = Profit
- Don't let fixed costs trick you into cutting spend
- The solution to negative profit is often more spend

## Principles

### 1. Contribution Margin Definition
```
Contribution Margin = Net Sales
  │
  ├─ Minus Product Cost
  ├─ Minus Variable Expense
  └─ Minus Ad Spend
```

### 2. Fixed Cost Trap
- Blended fixed cost per day (e.g., $1,000/day rent)
- If contribution margin < fixed cost = Negative profit
- But: Fixed cost as % of revenue goes down with volume
- Solution is often to increase spend, not cut it

### 3. Return Accrual
- January returns from December can make metrics look bad
- Don't process returns on a cash basis
- Accrue returns monthly based on expected return rate
- Apply to present revenue, not processing date

## Process

### Contribution Margin Management:
```
1. Calculate contribution margin daily
2. Set a goal for contribution margin
3. Have it in relationship to fixed costs
4. Don't let fixed costs create false signals
5. If contribution margin is positive, spend more
6. If contribution margin is negative, diagnose the problem
```

## Decision Framework

```
Should I Increase Ad Spend?
  │
  ├─ Is contribution margin positive?
  │   ├─ YES → Increase spend
  │   └─ NO → Diagnose the problem
  │
  ├─ Is the negative signal from fixed costs?
  │   ├─ YES → Spend more (fixed cost % will decrease)
  │   └─ NO → Fix the variable economics
  │
  ├─ Is there inventory to support it?
  │   ├─ YES → Spend more
  │   └─ NO → Pause until inventory arrives
  │
  └─ What's the marginal value of the next dollar?
      └─ Positive? Spend. Negative? Stop.
```

## Rules

**Always:**
- Track contribution margin daily
- Accrue returns monthly
- Understand the relationship to fixed costs
- Spend when contribution margin is positive

**Never:**
- Let fixed costs create a false signal
- Process returns on a cash basis
- Cut spend when contribution margin is positive
- Forget to reconcile accruals

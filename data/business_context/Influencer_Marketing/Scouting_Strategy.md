# Scouting_Strategy.md

## Purpose
To provide frameworks for influencer scouting at scale.

## Core Philosophy
**The algorithm decides what works, not you.**

- Give creators creative freedom
- Let them speak to their audience
- The algorithm will reward authenticity
- Forced content doesn't work

## Principles

**1. Use VPNs for Algorithm Diversity**
- Set iPads/iPhones across the country
- Different algorithms = Different creators
- Don't let everyone see same content
- Find moms in Kansas AND influencers in LA

**2. Vary Device Locations**
- One device = One location
- Different algorithms per device
- See different creator types
- Broaden your scouting net

**3. Scout for Your ICP**
- Identify where your avatar spends time
- Follow the same creators they follow
- Start narrow, expand over time
- Dominate niche then expand

## Process

**VPN Scouting Setup:**
```
Device 1: LA algorithm
  → Sees LA influencers

Device 2: Kansas algorithm
  → Sees Midwest creators

Device 3: NYC algorithm
  → Sees East coast content

Device 4: Random location
  → Algorithm diversity
```

## Decision Framework

```
Which Creators Should I Scout?
  |
  |- Is this my ICP?
  |   |- YES → Scout them
  |   |- NO → Pass
  |
  |- Do they have organic engagement?
  |   |- YES → Prioritize
  |   |- NO → Low priority
  |
  |- Is their audience in my geography?
  |   |- YES → Higher priority
  |   |- NO → Lower priority
  |
  |- Do they fit my brand?
      |- YES → Scout
      |- NO → Pass
```

## Rules

**Always:**
- Scout 24/7
- Use VPNs
- Vary locations
- Focus on ICP

**Never:**
- Let scouting become stale
- Ignore location diversity
- Only scout LA/NYC
- Forget to reset algorithms

## AI Instructions

When scouting influencers:
- Use location diversity
- Identify ICP-aligned creators
- Track engagement quality
- Build creator database
- Automate outreach where possible

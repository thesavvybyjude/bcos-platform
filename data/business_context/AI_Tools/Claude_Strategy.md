# Claude_Strategy.md

## Purpose
To provide a complete strategy for using Claude effectively.

## Core Philosophy
**Claude is the most intuitive AI because it understands how humans actually work.**

- Claude asks clarifying questions with A/B/C/D/E options
- Browser extension makes AI omnipresent
- Claude Code lets you program in English
- Claude has "soul" - it feels like a real assistant

## Principles

### 1. Claude Browser Extension
- Install on Chrome
- Your "buddy" on every website
- Can read and interact with web apps
- Slack, Gmail, spreadsheets, etc.

### 2. Claude Code
- Program in English, not code
- Build apps, dashboards, automations
- No coding experience required
- Just talk to it

### 3. Claude Has "Soul"
- Feels like a real assistant
- Asks the right questions
- Intuitive UI with options
- The tool that actually solves problems

## Process

### Claude Browser Extension Workflow:
```
1. Install Claude extension on Chrome
2. Open any web app (Slack, Gmail, spreadsheet)
3. Talk to Claude about what you need
4. Claude reads the page/app context
5. Claude performs actions or writes responses
6. You approve or tweak
7. Claude executes
```

## Decision Framework

```
When to Use Claude Features:
  │
  ├─ Daily work → Browser extension
  │
  ├─ Building software → Claude Code
  │
  ├─ Research → Claude Co-work
  │
  ├─ Visual outputs → "Visualize this"
  │
  └─ Email/Slack → Browser extension
```

## Rules

**Always:**
- Use Claude as primary LLM
- Install browser extension
- Use Claude Code for building
- Ask Claude to visualize

**Never:**
- Use ChatGPT as primary
- Ignore the browser extension
- Forget to use Claude Code
- Underestimate Claude's intuition

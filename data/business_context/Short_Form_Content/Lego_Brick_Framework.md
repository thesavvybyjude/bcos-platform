# Lego_Brick_Framework.md

## Purpose
To provide the atomic framework for short-form content creation.

## Core Philosophy
**Break content into Legos. Hold winners constant. Improve what's not.**

- Seven Lego brick categories
- Copy what's working (hold constant)
- Improve on the weak spots
- Restack into your own formation

## Principles

### 1. The Seven Lego Bricks
```
1. Topic
  └─ What the video is about

2. Angle
  └─ The unique take on the topic

3. Hook Structure
  ├─ Visual Hook (what's shown)
  ├─ Spoken Hook (what's said)
  └─ Text Hook (on-screen text)

4. Story Structure
  ├─ Case study
  ├─ Breakdown
  ├─ Listical
  ├─ Storytelling narrative
  └─ Video type

5. Visual Format
  ├─ Split screen
  ├─ Full screen
  ├─ Circle/corner
  ├─ In the world
  └─ Vlog POV

6. Key Visuals
  ├─ A-roll
  ├─ B-roll
  └─ Graphics

7. Audio
  ├─ Music
  └─ Sound effects
```

### 2. The Beginner's Strategy
- Hold as many constant as possible
- Topic and angle change every video
- Copy what's already working
- Don't invent new formats until you know the fundamentals

### 3. The Advanced Strategy
- Once you know the fundamentals, innovate
- Borrow from other industries
- Remix originally
- Be the first mover on one of the seven bricks

### 4. How to Copy
```
Find winning videos in your niche
  ↓
Explode into the seven pieces
  ↓
Hold constant what's world-class
  ↓
Improve on what's not
  ↓
Restack into your own Lego formation
  ↓
Post
```

## Process

### Lego Brick Analysis:
```
1. Watch a winning video
2. Ask: What's the topic?
3. Ask: What's the angle?
4. Ask: What's the hook structure?
5. Ask: What's the story structure?
6. Ask: What's the visual format?
7. Ask: What are the key visuals?
8. Ask: What's the audio?
9. Copy the winners
10. Improve on the rest
```

## Decision Framework

```
What Should I Copy vs. Innovate?
  │
  ├─ Am I a beginner?
  │   ├─ YES → Copy everything
  │   └─ NO → Innovate on 1-2 bricks
  │
  ├─ Is this format saturated?
  │   ├─ YES → Need differentiator
  │   └─ NO → Copy it
  │
  ├─ What are my unique strengths?
  │   └─ Innovate on those
  │
  └─ What's already working in my niche?
      └─ Copy it
```

## Rules

**Always:**
- Break content into Legos
- Copy what's working
- Improve on weak spots
- Restack uniquely

**Never:**
- Invent everything from scratch
- Copy without understanding
- Ignore what's working
- Try to be first mover on everything

# Visuals_Motion.md

## Purpose
To provide frameworks for visual elements in short-form content.

## Core Philosophy
**The brain is optimized to detect motion.**

- High motion = High attention
- Deer in the woods: head up when they sense motion
- The scroll stops when something moves
- Visuals stun, words tell, text confirms

## Principles

### 1. The Three Visual Attributes
```
High Motion
  └─ The brain locks onto motion
  └─ Adds artificial motion if needed

High Color
  └─ Stands out in the feed
  └─ Differentiates from others

High Contrast
  └─ Different from what's around it
  └─ Contrasting colors, lighting, etc.
```

### 2. Podcast Clips Are Hard
- Not much motion → Low attention
- Add subtle push-ins
- Add lens flares
- Best visuals have motion baked in

### 3. Interesting Visuals
- "Interesting" is mushy but everyone knows it
- Hot people win (play into it)
- B-roll needs to be interesting
- High motion, high color, high contrast

### 4. Thumbnail Covers (Instagram DMs)
- When shared in DMs, the thumbnail sits there
- It's not looping
- Get them to click with better covers
- Series covers help bingability

## Process

### Visual Optimization:
```
1. Ensure high motion (baked in or artificial)
2. Ensure high color (stand out in feed)
3. Ensure high contrast (different from others)
4. Make it interesting
5. Design thumbnail covers for DMs
6. Test and iterate
```

## Decision Framework

```
What Visuals Should I Use?
  │
  ├─ Is there motion?
  │   ├─ YES → Good
  │   └─ NO → Add artificial motion
  │
  ├─ Is there color?
  │   ├─ YES → Good
  │   └─ NO → Add color
  │
  ├─ Is there contrast?
  │   ├─ YES → Good
  │   └─ NO → Change it
  │
  └─ Is it interesting?
      ├─ YES → Good
      └─ NO → Find better visuals
```

## Rules

**Always:**
- Prioritize motion
- Use high color
- Create contrast
- Make it interesting

**Never:**
- Let visuals be static
- Use low color in a colorful feed
- Blend in
- Be boring

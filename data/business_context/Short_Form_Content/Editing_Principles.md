# Editing_Principles.md

## Purpose
To provide frameworks for short-form editing.

## Core Philosophy
**Speed to value is everything. Absorption rate is the KPI.**

- Every word, pixel, frame matters
- Comprehension decays over time
- Misaligned visuals kill retention
- The eyes-closed test reveals pacing issues

## Principles

### 1. Absorption Rate
- The most important metric in content
- 100% absorption = Viewers understand 100% of what you said
- Every frame can only maintain or decrease comprehension
- When comprehension hits a threshold, they bounce

### 2. The Eyes-Closed Test
- Close your eyes and listen to the video
- If you're bored → too slow
- If you can't keep up → too fast
- Find the sweet spot for pacing

### 3. Visual Alignment
- Visuals must match the words
- Wrong visuals at wrong times = Confusion
- If there's a visual that adds clarity, use it
- If it doesn't add clarity, don't use it

### 4. The Two Dopamine Hit Framework
```
Hit 1: Tell them something they can use
  → "The Instagram thumbnail in DMs matters"

Hit 2: Tell them something else they can use
  → "Here's why"

If you get them to two hits → They're locked in
```

### 5. The Sentence-Level Audit
- Write the first line → Opens a question
- Answer that question in the next line
- That opens another question
- Answer that question
- Repeat all the way through

## Process

### Editing Audit:
```
1. Watch the video
2. Close your eyes and listen
3. Is the pacing right?
4. Do the visuals match the words?
5. Sentence by sentence: Is it clear?
6. Have I given two dopamine hits?
7. Fix what's broken
```

## Decision Framework

```
What's Wrong With My Edit?
  │
  ├─ Is the pacing right?
  │   ├─ Too fast → Add breathing room
  │   └─ Too slow → Cut tighter
  │
  ├─ Do visuals match words?
  │   ├─ YES → Good
  │   └─ NO → Fix alignment
  │
  ├─ Have I given two dopamine hits?
  │   ├─ YES → Good
  │   └─ NO → Add value
  │
  └─ Is comprehension high?
      ├─ YES → Good
      └─ NO → Simplify
```

## Rules

**Always:**
- Prioritize absorption rate
- Use the eyes-closed test
- Align visuals with words
- Give two dopamine hits early

**Never:**
- Let pacing be off
- Use misaligned visuals
- Bait and switch
- Forget the dopamine hits

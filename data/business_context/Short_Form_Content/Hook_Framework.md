# Hook_Framework.md

## Purpose
To provide a complete framework for creating hooks.

## Core Philosophy
**The hook has three parts: Visual, Spoken, and Text.**

- They must all align
- Confusion leads to churn
- Comprehension is the KPI
- The hook's job is to stop the scroll

## Principles

### 1. The Three Hook Components
```
Visual Hook
  └─ What's shown on screen
  └─ Stuns the viewer (first job)

Spoken Hook
  └─ What's said
  └─ Context + Contrast

Text Hook
  └─ On-screen text
  └─ Context + Confirmation
```

### 2. The Hook Sequence
```
1. Visual Hook (stun)
   └─ High motion, high color, high contrast
   └─ Stuns the scroll

2. Context (set the stage)
   └─ First sentence: what is this about?
   └─ Top-down processing

3. Contrast (create curiosity)
   └─ What they expect vs. what's true
   └─ "Most people think X, but actually Y"
```

### 3. Contrast Types
```
Direct Contrast:
  ├─ "Most people think X"
  ├─ "I'm going to tell you why"
  └─ Reveal the opposite

Implied Contrast:
  ├─ Ask a surprising question
  ├─ Make a contrarian statement
  └─ Let viewer complete the puzzle
```

### 4. The Opposite of Confusion
- Confusion → Churn
- Comprehension → Watch
- All three hooks must align
- If they don't match, people bounce

## Process

### Hook Creation:
```
1. Visual hook: Stun with motion/color/contrast
2. Text hook: Set context ("What makes a good hook?")
3. Spoken hook: Add context and contrast
4. All three must match
5. Test comprehension
6. If confused, rewrite
```

## Decision Framework

```
What's Wrong With My Hook?
  │
  ├─ Are the three hooks aligned?
  │   ├─ YES → Good
  │   └─ NO → Fix alignment
  │
  ├─ Is there context in the first sentence?
  │   ├─ YES → Good
  │   └─ NO → Add context
  │
  ├─ Is there contrast?
  │   ├─ YES → Good
  │   └─ NO → Add contrast
  │
  └─ Am I clear on what the video is about?
      ├─ YES → Good
      └─ NO → Simplify
```

## Rules

**Always:**
- Align all three hooks
- Add context in first sentence
- Add contrast
- Prioritize comprehension

**Never:**
- Confuse the viewer
- Miss context
- Forget contrast
- Have misaligned hooks

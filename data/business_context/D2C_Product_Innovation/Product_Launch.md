# Product_Launch.md

## Purpose
To provide a framework for evaluating and launching new products.

## Core Philosophy
**Product launches are lottery tickets. You have no idea what will work.**

- Some products work, some don't
- It's totally random
- Give yourself room to fail
- Never bet the farm

## Principles

**1. The Three-Part Framework**
```
1. CAC vs LTV
   ├─ CAC product: Can I acquire new customers?
   └─ LTV product: Sell to existing customers?

2. LTV Ramifications
   ├─ Does it fuel LTV for the rest of the business?
   └─ Example: Luggage customers buy wallets

3. Distribution X Factor
   ├─ Works on Amazon?
   └─ Works in wholesale?
```

**2. CAC Product Characteristics**
- Price point over $50
- Large enough TAM
- Not a complement to existing products
- Can acquire net new customers

**3. The Lottery Ticket Mentality**
- Product launches = Lottery tickets
- Watches: Massive flop
- Rings: Immediate success
- You have no idea what will work
- Try a bunch of stuff

**4. Keep Costs Low**
- Limit new product launch cost to under $500K
- Don't care about minimum quantities
- Only do it if you can do it for less
- Give yourself room to fail

## Process

**Product Launch Process:**
```
1. Test new product on email list
2. Test on organic (social)
3. Test on paid (small budget)
4. If it wins on all three → Scale
5. If it doesn't → Move on
6. Never bet the farm
7. Repeat
```

## Decision Framework

```
Should We Launch This Product?
  │
  ├─ Is it a CAC or LTV product?
  │   ├─ CAC → Can I acquire new customers?
  │   └─ LTV → Will existing customers buy?
  │
  ├─ Does it fuel LTV?
  │   ├─ YES → Good
  │   └─ NO → Maybe not
  │
  ├─ Does it work on Amazon or wholesale?
  │   ├─ YES → Good
  │   └─ NO → Maybe not
  │
  └─ Can we launch it for under $500K?
      ├─ YES → Launch
      └─ NO → Skip
```

## Rules

**Always:**
- Launch for under $500K
- Test on email, organic, paid
- Treat launches as lottery tickets
- Never bet the farm

**Never:**
- Spend millions on a launch
- Think you know what will work
- Keep failing products alive
- Ignore the three-part framework

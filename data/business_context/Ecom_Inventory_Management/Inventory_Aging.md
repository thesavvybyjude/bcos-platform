# Inventory_Aging.md

## Purpose
To provide frameworks for managing aging inventory.

## Core Philosophy
**Inventory sitting on shelves is cash sitting on shelves.**

- Bad inventory purchases are how you die in e-commerce
- Turn aging inventory back into cash
- Liquidate what doesn't move
- Make new bets with the cash

## Principles

### 1. The A/B/C/D Grading System
```
A-Grade: Fresh inventory (high velocity)
B-Grade: Moderate aging (medium velocity)
C-Grade: Significant aging (low velocity)
D-Grade: Dying inventory (no velocity)
```

### 2. The Liquidation Decision
- The willingness to discount should relate to days of inventory
- If it's not moving, liquidate it
- Use unlisted PDPs (not on main website)
- Run ads at lower efficiency (0.8-1x ROAS)

### 3. Two Liquidation Options
```
Option 1: Discount heavily on funnel
  ├─ Only available through ad (not website)
  └─ Exclude existing customers

Option 2: Accept lower efficiency
  ├─ Run ads at 0.8-1x ROAS
  └─ Move through inventory quickly
```

### 4. The Cash Flow Impact
- Aged inventory is a cash flow suck
- It's decaying value by the day
- Holding it props up asset-to-liability ratio artificially
- Sophisticated buyers won't value it at retail

## Process

### Inventory Management:
```
1. Track inventory by age (days in warehouse)
2. Grade A/B/C/D
3. For D-grade: Liquidate immediately
4. For C-grade: Consider liquidation or heavy promotion
5. For B-grade: Monitor closely
6. For A-grade: Protect and maximize margin
7. Repeat weekly
```

## Decision Framework

```
What Should I Do With This Inventory?
  │
  ├─ Days of inventory < 30 → Protect margin
  │
  ├─ Days of inventory 30-90 → Monitor
  │
  ├─ Days of inventory 90-180 → Consider discounting
  │
  └─ Days of inventory > 180 → Liquidate immediately
```

## Rules

**Always:**
- Track inventory age
- Liquidate D-grade inventory
- Use unlisted PDPs
- Make new bets with cash

**Never:**
- Hold aging inventory
- Prop up balance sheet with dead inventory
- Ignore inventory age
- Pay storage fees for unsold inventory

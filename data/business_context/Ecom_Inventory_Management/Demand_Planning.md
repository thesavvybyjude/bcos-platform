# Demand_Planning.md

## Purpose
To provide frameworks for demand planning in e-commerce.

## Core Philosophy
**Demand creation must match demand planning.**

- Place a PO with a demand creation plan
- Marketing, ops, and finance must be aligned
- The worst mistake: PO devoid of marketing plan
- Every PO should have a sell-through plan

## Principles

### 1. The Demand Plan
```
PO = X units
  │
  ├─ Sell X through email/SMS to existing customers
  ├─ Sell X through influencer seeding
  ├─ Sell X through paid media (at Y efficiency)
  ├─ Sell X through organic social
  └─ Therefore, need Z dollars of media spend
```

### 2. Small Bets Scale Into Large Ones
- Place a small PO to test demand
- Learn the efficiency
- Then scale
- Don't place a large PO on assumed efficiency

### 3. Two Supply Chains
- Flexible low-MOQ supply chain (test demand)
- Large-scale PO supply chain (scale success)
- ColourPop model: Make 100 units, test demand, then place PO

### 4. Product Expansion Risk
- New product = Unknown efficiency
- Assume wide error bars
- Place small bets first
- Scale winners

## Process

### Demand Planning:
```
1. Identify new product opportunity
2. Place small test PO
3. Run ads to test demand
4. Measure efficiency
5. If positive, scale PO
6. Create full demand plan
7. Align marketing, ops, finance
8. Execute
```

## Decision Framework

```
What Size PO Should I Place?
  │
  ├─ Do I have historical efficiency data?
  │   ├─ YES → Model expected sales
  │   └─ NO → Start with small PO
  │
  ├─ Do I have a demand plan?
  │   ├─ YES → Place PO
  │   └─ NO → Build plan first
  │
  ├─ Is this a new category?
  │   ├─ YES → Very small PO
  │   └─ NO → Model based on historical
  │
  └─ What's the cash available?
      └─ Don't bet the farm on unknown efficiency
```

## Rules

**Always:**
- Build a demand plan with every PO
- Start small on new products
- Test before scaling
- Align marketing, ops, and finance

**Never:**
- Place a PO without a demand plan
- Assume efficiency on new categories
- Scale before testing
- Silos marketing from inventory planning

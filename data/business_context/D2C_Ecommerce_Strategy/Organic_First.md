# Organic_First.md

## Purpose
To provide a framework for using organic content before paid ads.

## Core Philosophy
**Don't spend money on advertising until you figure out how to make a good video.**

- Organic content should take you to $10M in sales
- Organic is the proving ground for paid
- Every good organic video = Free $10 in CPM value
- Smaller brands have an unfair advantage here

## Principles

**1. Organic First, Always**
```
Starting Brand:
  └─ Get really good at short-form content
  └─ That should take you to $10M in sales
  └─ Then start spending money on ads
```

**2. Organic = Free CPM**
- Good video gets 1,000 views for free
- That's $10 of free ad spend
- Every video = Potential free $10
- Multiple videos = Free scale

**3. Organic is the Proving Ground**
- If people like it organically, they'll like it as an ad
- Best performing organic = Best performing paid
- 70% of best paid ads are best organic ads
- Run the gauntlet: Organic first, Paid second

**4. The Unfair Advantage**
- Bigger brands are bad at organic (pre-2021 brands)
- Smaller brands can win on organic
- It's an unfair advantage
- Build multiple accounts to test more

## Process

**Organic to Paid Workflow:**
```
1. Create organic content
2. Post on Instagram, TikTok, YouTube Shorts
3. Find winners (high engagement, views)
4. Take winners into paid
5. Run in meta
6. Scale winners
7. Repeat weekly
```

## Decision Framework

```
Should I Spend on Ads?
  │
  ├─ Do I have good organic content?
  │   ├─ YES → Test in paid
  │   └─ NO → Get good at organic first
  │
  ├─ Am I at $10M+ in sales?
  │   ├─ YES → Consider paid
  │   └─ NO → Stay organic
  │
  ├─ Do I have multiple organic accounts?
  │   ├─ YES → Testing more = More winners
  │   └─ NO → Create more accounts
  │
  └─ Are my best organic videos winning in paid?
      ├─ YES → Scale paid
      └─ NO → Improve organic first
```

## Rules

**Always:**
- Start with organic
- Test organic before paid
- Create multiple organic accounts
- Use organic winners in paid

**Never:**
- Start with paid
- Ignore organic
- Think you're too big for organic
- Outsource organic creation

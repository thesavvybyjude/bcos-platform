# Zero_X_or_Ten_X.md

## Purpose
To provide a framework for resource allocation.

## Core Philosophy
**If it's working, 10x it. If it's not, 0x it.**

- 1x efforts are wasted time
- Small bets don't move the needle
- Success should be amplified immediately
- Failure should be cut immediately

## Principles

### 1. The 0x or 10x Decision
```
If something is working:
  → 10x it
  → Scale what's working
  → Compound success

If something is not working:
  → 0x it
  → Stop immediately
  → Don't waste resources
```

### 2. The 1x Trap
- $20,000 event with C-level on calls
- Wasting time on small bets
- Mental overhead > Actual outcome
- Even if it doubles, it doesn't matter

### 3. Nothing Is Static
- If it's working, jam more resources
- If it's not, stop immediately
- Every day, every plane of attack
- No lazy middleground

## Process

### 0x or 10x Framework:
```
1. Ask: "If this doubles/10xes, does it change my business?"
2. If NO: Stop doing it or 10x it
3. If YES: Evaluate if it's actually working
4. If working: 10x it immediately
5. If not working: 0x it immediately
6. Repeat constantly
```

## Decision Framework

```
What's the Right Bet Size?
  │
  ├─ Is this initiative working?
  │   ├─ YES → Consider 10x
  │   └─ NO → Consider 0x
  │
  ├─ If it 10xes, does it move the needle?
  │   ├─ YES → Worth pursuing
  │   └─ NO → Not worth time
  │
  ├─ Is the overhead worth it?
  │   ├─ YES → Keep investing
  │   └─ NO → Stop
  │
  └─ What's the data telling me?
      ├─ Positive → 10x
      └─ Negative → 0x
```

## Rules

**Always:**
- 10x what works
- 0x what doesn't
- Move fast on decisions
- Compound success

**Never:**
- Waste time on 1x efforts
- Linger on failing initiatives
- Ignore data
- Be lazy about bet sizing

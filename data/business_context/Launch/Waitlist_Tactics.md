# Waitlist_Tactics.md

## Purpose
To provide tactical frameworks for building pre-launch momentum.

## Core Philosophy
**A waitlist is a demand validation engine, not just a list of emails.**

## Principles

**1. Set Public Goals**
- "I need 1,000 subscribers before launch"
- Public commitment creates accountability
- Community rallies to help
- Achievement becomes content

**2. Create Social Proof Early**
- Show who's already signed up
- Share testimonials (even at waitlist stage)
- Make it clear this is valuable
- Build FOMO

**3. Make Signing Up Easy**
- One-click signup
- Clear value proposition
- No friction
- Mobile-optimized

## Process

**Building a Waitlist:**
```
1. Announce your intention
2. Set a specific goal (e.g., 1,000 subscribers)
3. Create a simple landing page
4. Share daily updates on progress
5. Celebrate milestones publicly
6. Launch when threshold is hit
```

## AI Instructions

When creating waitlist content:
- Be specific about what they'll get
- Create urgency without being pushy
- Show social proof
- Make the signup process frictionless
- Follow up with regular updates

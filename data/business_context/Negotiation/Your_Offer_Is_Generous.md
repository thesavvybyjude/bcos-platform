# Your_Offer_Is_Generous.md

## Purpose
To provide a framework for rejecting offers without alienating the other party.

## Core Philosophy
**"Your offer is very generous. It just doesn't work for me" is the politest no.**

- It calls them generous (even when they're stingy)
- It nurtures generosity
- It avoids external criteria arguments
- It's impossible to argue with

## Principles

**1. Why It Works**
```
1. It calls them generous
   └─ Even when they're being stingy
   └─ They'll want to be more generous
   └─ You nurture positive behavior

2. "It doesn't work for me"
   └─ They can't argue with it
   └─ You have proprietary information
   └─ You're the only one who knows your internal data
   └─ External criteria is irrelevant
```

**2. Avoid External Criteria**
- "Well, the market says X"
- "People in my role make Y"
- These are traps
- You'll never agree on the numbers
- It limits you (what if you could pay more?)

**3. The Gradual No**
- You're warning them that "no" is coming
- You're giving them a chance to adjust
- It's collaborative, not confrontational
- You've been heard and respected

**4. The Follow-Up Email**
- If both sides retire to think
- Send an email to the principal spokesperson
- Say: "I appreciate how hard you worked on bringing the deal to the table"
- Nothing else
- Emotional compensation is worth 4x dollar compensation

## Process

**Rejecting an Offer:**
```
1. "Your offer is very generous"
2. "It just doesn't work for me"
3. Wait for response
4. They may adjust
5. If they don't, you've warned them no is coming
6. If needed, send appreciation email
7. Emotional compensation = Higher chance of modification
```

## Decision Framework

```
Should I Accept This Offer?
  │
  ├─ Does it work for me?
  │   ├─ YES → Accept
  │   └─ NO → Use the line
  │
  ├─ Is the offer generous?
  │   ├─ YES → Acknowledge it
  │   └─ NO → Still say it's generous (nurture generosity)
  │
  ├─ Am I backing into a corner?
  │   ├─ YES → Use the line
  │   └─ NO → Other approach
  │
  └─ Should I send appreciation?
      ├─ YES → Send it
      └─ NO → Continue
```

## Rules

**Always:**
- Call the offer generous
- Say it doesn't work for you
- Avoid external criteria
- Send appreciation if needed

**Never:**
- Argue external criteria
- Say "You're not being generous"
- Forget emotional compensation
- Reject without warning

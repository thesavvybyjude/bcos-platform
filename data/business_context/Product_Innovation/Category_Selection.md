# Category_Selection.md

## Purpose
To provide frameworks for selecting product categories.

## Core Philosophy
**Choose categories that are stale but growing.**

- Stale = No innovation
- Growing = Demand exists
- Stale + Growing = Opportunity
- You don't need to be first

## Principles

**1. Look for Stale Categories**
- No innovation in years
- Products don't taste good
- Designs are boring
- Everyone is complacent

**2. Ensure the Category Is Growing**
- Overall category still growing
- Consumer demand exists
- New entrants are winning
- Market size is expanding

**3. Leverage Existing Infrastructure**
- Same supply chain
- Same distribution
- Same retailers
- Faster execution

## Category Selection Checklist

```
[ ] Category is saturated
[ ] Category is stale (no innovation)
[ ] Category is growing
[ ] Existing infrastructure exists
[ ] I can fill a white space
[ ] My team can execute
[ ] My community wants it
```

## Decision Framework

```
Which Category Should I Enter?
  |
  |- Is it saturated?
  |   |- YES → Good
  |   |- NO → You'll educate
  |
  |- Is it stale?
  |   |- YES → Opportunity
  |   |- NO → Hard to differentiate
  |
  |- Is it growing?
  |   |- YES → Enter
  |   |- NO → Don't
  |
  |- Is there white space?
      |- YES → Enter
      |- NO → Find another
```

## Rules

**Always:**
- Enter saturated categories
- Enter stale categories
- Enter growing categories
- Leverage infrastructure

**Never:**
- Enter declining categories
- Create new categories
- Ignore infrastructure
- Underestimate execution

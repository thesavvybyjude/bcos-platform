# Deal_Tells.md

## Purpose
To provide a framework for recognizing deal tells.

## Core Philosophy
**The signs are there if you look for them.**

- Yellow flags become red flags
- Some people are unreachable (7%)
- Look for early signs
- Move on when you need to

## Principles

**1. The 7% Unreachable**
- About 7% of people you will never make a deal with
- Recognize them early
- Recognize when it's time to move on
- Don't waste time

**2. Early Signs**
```
Yellow flags that become red flags:
  ├─ Only focused on one aspect of the deal
  ├─ Continually attacking you
  ├─ Continually blaming you
  ├─ Acting like your victim when they weren't
  └─ If they do both (attack + victim) → Unreachable
```

**3. Body Language Tells**
- If words, tone, and body language don't line up = Problem
- When there's misalignment, something is wrong
- 7-38-55 theory: 7% words, 38% tone, 55% body language
- Real issue is when they don't line up

**4. The Answer Too Quickly**
- Somebody answers too quickly = They have a plan
- They're not really listening
- Could be manipulation or stupidity
- Either way, it doesn't work out

## Process

**Reading the Deal:**
```
1. Watch for early signs
2. Yellow flags become red flags
3. Check for alignment between words, tone, body language
4. Notice if they answer too quickly
5. If they're doing both attack + victim → Move on
6. If they're unreachable → Move on
7. Don't waste time
```

## Decision Framework

```
Should I Continue This Deal?
  │
  ├─ Are they in the 7% unreachable?
  │   ├─ YES → Walk away
  │   └─ NO → Continue
  │
  ├─ Are they only focused on one aspect?
  │   ├─ YES → Yellow flag
  │   └─ NO → Good
  │
  ├─ Are they attacking and victim?
  │   ├─ YES → Unreachable
  │   └─ NO → Continue
  │
  └─ Are words, tone, body language aligned?
      ├─ YES → Good
      └─ NO → Problem
```

## Rules

**Always:**
- Watch for early signs
- Check alignment
- Trust your intuition
- Move on when needed

**Never:**
- Ignore yellow flags
- Think you can reach everyone
- Waste time on unreachable people
- Forget body language

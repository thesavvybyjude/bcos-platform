# Bargaining_Framework.md

## Purpose
To provide a complete framework for bargaining.

## Core Philosophy
**Bargaining is the last resort—not your first move.**

- Try to make a deal without bargaining
- If you must bargain, use the 65/85/95/100 framework
- Emotional anchoring before financial anchoring
- Odd numbers create precision

## Principles

**1. The 65/85/95/100 Framework**
```
Target Price: $10M

Start at 65% ($6.5M)
  └─ Emotional anchoring first
  └─ "You're going to be really angry with me"
  └─ Softens the blow

Second move: 85% ($8.5M)
  └─ Feels like a victory
  └─ Each increase is half the previous

Third move: 95% ($9.5M)
  └─ Smaller victory
  └─ Feels like squeezing

Fourth move: 100% ($9,956,634)
  └─ Odd number = Precise calculation
  └─ Feels like a huge victory
```

**2. Before the First Number**
- Hit them with heavy empathy
- Accusations audit
- "I would be lucky to make a deal with you"
- "This is worth a lot"
- "I'm actually scared to tell you the number"

**3. Between Each Offer**
- Hit them with empathy
- Tell them how much you love their product
- Tell them it's worth everything they're asking
- Say everything in their head before they say it
- Leave them with nothing to say

**4. The Rules**
- Never bargain against yourself
- Never counter-offer until they've countered
- Each increase should be half the previous
- End with an incredibly odd number

## Process

**Bargaining:**
```
1. Emotional anchoring (they expect worse)
2. First number: 65% of target
3. Empathy between each offer
4. Wait for their counter
5. Second number: 85% of target
6. Wait for their counter
7. Third number: 95% of target
8. Wait for their counter
9. Final number: 100% with odd precision
10. They feel like they won
```

## Decision Framework

```
Should I Bargain?
  │
  ├─ Can I avoid bargaining?
  │   ├─ YES → Avoid it
  │   └─ NO → Use the framework
  │
  ├─ Do I need to move on numbers?
  │   ├─ YES → Bargain
  │   └─ NO → Don't
  │
  ├─ Is this the last resort?
  │   ├─ YES → Use the framework
  │   └─ NO → Use other tactics
  │
  └─ Am I prepared for the 65/85/95/100?
      ├─ YES → Use it
      └─ NO → Get prepared
```

## Rules

**Always:**
- Bargain last
- Use emotional anchoring first
- Never bargain against yourself
- End with an odd number

**Never:**
- Bargain first
- Skip emotional anchoring
- Bargain against yourself
- Use round numbers at the end

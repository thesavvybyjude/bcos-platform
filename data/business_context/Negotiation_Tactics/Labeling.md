# Labeling.md

## Purpose
To provide a framework for using labels in communication.

## Core Philosophy
**Labels are verbal observations of emotions or dynamics.**

- Labels draw people out
- They make people feel heard
- They deactivate negativity
- They build connection

## Principles

**1. What Is a Label?**
- A verbal observation of an emotion or dynamic
- "It seems like you're engaged"
- "It looks like you're in a hurry"
- "It feels like you're frustrated"

**2. Label Formats**
```
It seems like...
It sounds like...
It looks like...
It feels like...

"You seem angry"
"Seems like you're in a hurry"
"Seems like you have a reason for saying that"
```

**3. Why Labels Work**
- Draws people out
- Makes them feel heard
- Not an accusation (it's an observation)
- Open to correction
- People feel very engaged

**4. Label vs. Mirror**
- Labels = Right-handed for most people
- Mirrors = Left-handed for some
- Choose what's comfortable
- Both work

## Process

**Using Labels:**
```
1. Observe an emotion or dynamic
2. Label it: "It seems like..."
3. Wait for response
4. They'll either confirm or correct
5. Either way, you've engaged them
6. Continue
```

## Decision Framework

```
Should I Use a Label or a Mirror?
  │
  ├─ Am I right-handed with this?
  │   ├─ YES → Use a label
  │   └─ NO → Use a mirror
  │
  ├─ Do I need to draw them out?
  │   ├─ YES → Label works
  │   └─ NO → Maybe not needed
  │
  ├─ Is it an emotion or dynamic?
  │   ├─ YES → Use a label
  │   └─ NO → Mirror might work
  │
  └─ Am I comfortable with it?
      ├─ YES → Use it
      └─ NO → Practice more
```

## Rules

**Always:**
- Use labels as observations, not accusations
- Start with "It seems like..."
- Wait for response
- Be comfortable with correction

**Never:**
- Accuse with a label
- Be rigid about the observation
- Forget to wait
- Use a label when you're not sure

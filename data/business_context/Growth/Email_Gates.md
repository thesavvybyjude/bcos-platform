# Email_Gates.md

## Purpose
To provide a framework for using email gates (hard gates) for subscriber acquisition.

## Core Philosophy
**Every piece of content is a subscriber acquisition channel.**

- If they're reading, they're interested
- If they're interested, they'll give email
- Email gate = 100% conversion intent
- Content = Distribution vehicle

## Principles

**1. Gate Every Piece of Content**
- All long-form content gets a gate
- Social posts drive to gated content
- Email gate after 2-3 sentences
- Clear value proposition

**2. Make It Clear It's Free**
- "No payment, just your email"
- Overcome the paywall objection
- Free access is low friction
- Email = fair exchange

**3. Leverage Exclusivity**
- "Behind the scenes" content
- "Untold" stories
- "Exclusive" access
- Personal content

## Process

**Email Gate Setup:**
```
1. Publish social teaser
2. Drive clicks to gated content
3. Show first 2-3 sentences
4. Hard gate appears
5. User enters email
6. Full content unlocked
```

## Decision Tree

```
Should I Use an Email Gate?
  |
  |- Is this high-value content?
  |   |- YES → Gate it
  |   |- NO → Skip
  |
  |- Does this build trust?
  |   |- YES → Gate it (trust = subscription)
  |   |- NO → Skip
  |
  |- Is this a unique story?
  |   |- YES → Gate it
  |   |- NO → Skip
  |
  |- Is my audience segment valuable?
      |- YES → Gate it
      |- NO → Use soft gate (pop-up)
```

## Rules

**Always:**
- Show enough value before gate
- Make gate frictionless
- Deliver immediately after signup
- Track conversion rate

**Never:**
- Gate low-value content
- Make signup process hard
- Forget to follow up
- Lose context in delivery

## AI Instructions

When using email gates:
- Create compelling teaser content
- Position gate as fair exchange
- Make value proposition clear
- Automate follow-up sequence
- Segment subscribers by source

# Progressive_Peaking.md

## Purpose
To provide frameworks for progressive peaking in marketing.

## Core Philosophy
**Build peaks on top of each other.**

- Don't just peak at Black Friday
- Create peaks in April, June, September
- Each peak builds on the last
- Progressive peaking compounds

## Principles

### 1. The Peak Effect
- Black Friday/Cyber Monday: Everyone's conversion goes up
- You don't gain unique advantage
- Create peaks when others don't
- When no one else has a peak, you arbitrage the market

### 2. Progressive Peaking
```
Peak 1: April (spring launch)
  │
  ├─ Builds audience
  ├─ Tests creative
  └─ Establishes rhythm
  │
Peak 2: June (summer push)
  │
  ├─ Builds on April learnings
  ├─ Bigger audience
  └─ Higher conversion
  │
Peak 3: September (fall push)
  │
  ├─ Builds on June learnings
  ├─ Even bigger audience
  └─ Even higher conversion
  │
Peak 4: November (Black Friday)
  │
  └─ Maximum conversion, but not unique
```

### 3. The Halo Effect
- New customer acquisition from peaks → Future peaks
- Each peak builds the audience for the next
- The compounding effect is massive
- Don't just peak once—peak progressively

## Process

### Progressive Peaking Workflow:
```
1. Plan peaks throughout the year
2. Each peak builds on the previous
3. Test creative at each peak
4. Scale what works
5. Build audience for next peak
6. Compound the effect
```

## Decision Framework

```
When Should I Peak?
  │
  ├─ Cultural moment fits my brand?
  │   ├─ YES → Peak
  │   └─ NO → Create your own
  │
  ├─ Is there a story?
  │   ├─ YES → Peak
  │   └─ NO → Skip
  │
  ├─ Can I build on a previous peak?
  │   ├─ YES → Progressive peak
  │   └─ NO → Start fresh
  │
  └─ What's the SKU?
      └─ Limited edition, high AOV, high margin
```

## Rules

**Always:**
- Create peaks when others don't
- Build peaks progressively
- Answer "Why today?"
- Manufacture moments

**Never:**
- Rely only on Black Friday
- Ignore the halo effect
- Let the market set your conversion rate
- Forget to answer "Why today?"

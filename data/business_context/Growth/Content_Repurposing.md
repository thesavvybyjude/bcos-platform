# Content_Repurposing.md

## Purpose
To provide frameworks for maximizing content ROI through strategic repurposing.

## Core Philosophy
**Content is an asset, not an event.**

- One piece = Multiple assets
- Create once, distribute many times
- Different platforms = Different formats
- Every piece has a secondary life

## Principles

**1. Repurpose Long-Form to Short-Form**
- Newsletter → Tweet thread
- Article → LinkedIn post
- Podcast → Video clips
- Video → Transcript → Newsletter

**2. Create Multiple Assets Per Piece**
```
1 Newsletter (1,500 words)
  |
  |- 5-6 Tweets
  |- 1 LinkedIn post
  |- 1 Instagram post
  |- 1 Thread
  |- 1 LinkedIn article
```

**3. Use AI for Repurposing**
- Newsletter → Tweet thread
- Long-form → Short-form
- Transcript → Social posts
- Multiple formats from one source

## Process

**Content Repurposing Workflow:**
```
1. Create primary content (Newsletter/Video/Podcast)
2. Extract key insights
3. Repurpose to:
   - Tweet thread (5-6 tweets)
   - LinkedIn post
   - Instagram story
   - Short video clips
4. Schedule across platforms
5. Link back to primary content
6. Measure performance
7. Optimize based on data
```

## Rules

**Always:**
- Repurpose every piece of content
- Use AI tools for scaling
- Link back to primary source
- Test different formats

**Never:**
- Post same content identically across platforms
- Ignore platform-native formats
- Forget to drive traffic back
- Underestimate distribution

## AI Instructions

When repurposing content:
- Extract key takeaways
- Create platform-native formats
- Include calls-to-action
- Link back to full content
- Maintain consistent voice
- Test and iterate formats

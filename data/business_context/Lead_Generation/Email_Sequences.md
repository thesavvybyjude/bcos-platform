# Email_Sequences.md

## Purpose
To provide frameworks for email sequences.

## Core Philosophy
**Email is the only owned channel. Nurture it.**

- People open email at crazy rates
- People buy from email
- Email is not fully taken over by algorithms
- The welcome sequence + FOMO sequence = 9 days to conversion

## Principles

### 1. The Welcome Sequence (5 Days)
```
Day 1: Welcome + Case Studies → Sell/Book Call
Day 2: Why You Created This → Sell/Book Call
Day 3: Deeper Value → Context
Day 4: More Value → More Context
Day 5: FOMO → Final Push
```

### 2. The FOMO Sequence (4 Days)
```
Day 6: Case Studies
Day 7: Why It Exists
Day 8: Social Proof
Day 9: Scarcity/FOMO → Final Push
```

### 3. The Indoctrination Goal
- 9 days to indoctrinate someone to your brand
- They know what you're about
- They've been sold on it
- 15% conversion within 9 days is achievable

### 4. Weekly Newsletter
- Two types: Curation or Story + System
- Curation: Roundup, 5-bullet Friday
- Story + System: Deeper value, generosity
- Someone may convert in 1 month or 4 years

## Process

### Email Sequence Setup:
```
1. Create welcome sequence (5 emails)
2. Create FOMO sequence (4 emails)
3. Set up weekly newsletter
4. Automate all sequences
5. Monitor open rates (60%+ target)
6. Monitor conversion (15%+ target)
7. Iterate and improve
```

## Decision Framework

```
What's Wrong With My Email Sequence?
  │
  ├─ Is there a welcome sequence?
  │   ├─ YES → Good
  │   └─ NO → Create one
  │
  ├─ Is there a FOMO sequence?
  │   ├─ YES → Good
  │   └─ NO → Create one
  │
  ├─ Are open rates >40%?
  │   ├─ YES → Good
  │   └─ NO → Improve subject lines
  │
  └─ Is conversion >10%?
      ├─ YES → Good
      └─ NO → Improve offer/sequence
```

## Rules

**Always:**
- Create welcome + FOMO sequences
- Automate sequences
- Monitor open rates
- Target 15% conversion within 9 days

**Never:**
- Neglect email sequences
- Forget to automate
- Let open rates drop
- Ignore conversion data

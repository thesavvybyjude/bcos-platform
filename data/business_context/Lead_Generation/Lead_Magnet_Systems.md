# Lead_Magnet_Systems.md

## Purpose
To provide a framework for lead magnet systems.

## Core Philosophy
**Lead magnets are the hemoglobin of the funnel.**

- Give free value for email
- Content creates curiosity, lead magnet captures
- Email is the only channel not fully taken over by algorithms
- Lead magnets are the rails of the funnel

## Principles

### 1. Types of Lead Magnets
```
1. One-off PDF/Doc
   └─ "Here's my framework. Download below."

2. 3-5 Day Email Series
   └─ "Delivered over 5 days. Enter email."

3. Free Community
   └─ "Join our community. Enter email."

4. Waitlist
   └─ "Join the waitlist. Enter email."

5. Form
   └─ "Fill out this form. Enter email."
```

### 2. Native Embeds
- Don't break the hypnosis
- Weave it into the conversation
- Set up the conversation so lead magnet is the answer
- Example: Talk about editors → "Want my editors? Link below."

### 3. The Content-to-Email Loop
```
Content → Lead Magnet → Email → Trust → Offer → Sale
```

### 4. Native Ads vs. Non-Native Ads
```
Non-Native Ad:
  └─ "We'll be right back. Buy this couch."
  └─ Breaks hypnosis

Native Ad:
  └─ Weave into conversation
  └─ Doesn't break hypnosis
```

## Process

### Lead Magnet System:
```
1. Create content
2. Native embed lead magnet
3. Get email
4. Welcome sequence (5 days)
5. FOMO sequence (4 days)
6. Weekly newsletter
7. Offer sale
```

## Decision Framework

```
What Lead Magnet Should I Use?
  │
  ├─ Is this a simple idea?
  │   ├─ YES → PDF/Doc
  │   └─ NO → Email series
  │
  ├─ Do I have a community?
  │   ├─ YES → Free community
  │   └─ NO → Start simple
  │
  ├─ Is it time-sensitive?
  │   ├─ YES → Waitlist
  │   └─ NO → Standard
  │
  └─ Do I need to qualify?
      ├─ YES → Form
      └─ NO → Simple email capture
```

## Rules

**Always:**
- Native embed lead magnets
- Get email in exchange for value
- Don't break the hypnosis
- Make it easy to opt in

**Never:**
- Break away for non-native ads
- Forget to capture email
- Overcomplicate the lead magnet
- Bait and switch

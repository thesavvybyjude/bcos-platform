# Portfolio_Theory.md

## Purpose
To provide frameworks for managing partnership portfolios.

## Core Philosophy
**Don't bet everything on one partner. Build a portfolio.**

- One celebrity co-founder is risky
- Multiple partners create optionality
- Some will outperform massively
- Some will underperform

## Principles

### 1. Don't Put All Chips on One Bet
- One celebrity co-founder = High risk
- If it doesn't work, you're stuck
- Portfolio approach = Hedged
- Multiple partners = Multiple chances

### 2. Stair-Step Into Deals
```
Step 1: Micro influencers ($1-5K)
Step 2: Mid-tier influencers ($5-50K)
Step 3: Tier 1 athletes ($50-250K)
Step 4: A-list celebrities ($250K-1M+)
```

### 3. Diversify Across Verticals
```
Partnership Portfolio
  │
  ├─ Sports (MMA, Running, Golf)
  ├─ Science (Longevity, Nutrition)
  ├─ Entrepreneurship (Podcasts)
  ├─ Media (Newsletters)
  └─ Culture (TikTok, Instagram)
```

### 4. Partners Can Work with Partners
- Jon Jones on Joe Rogan
- Science advisor on partner podcast
- Co-mingling creates explosion
- Network effects within portfolio

## Process

### Building a Partnership Portfolio:
```
1. Identify 3-5 verticals
2. Start small in each vertical
3. Test and learn
4. Double down on winners
5. Add bigger partners
6. Cross-pollinate partners
7. Portfolio compounds
```

## Decision Framework

```
How to Manage Partnership Portfolio?
  │
  ├─ Do I have multiple partners?
  │   ├─ YES → Good
  │   └─ NO → Need diversification
  │
  ├─ Do I have vertical diversification?
  │   ├─ YES → Good
  │   └─ NO → Need more verticals
  │
  ├─ Am I stair-stepping?
  │   ├─ YES → Smart
  │   └─ NO → Risk of overpaying
  │
  └─ Are partners co-mingling?
      ├─ YES → Explosive potential
      └─ NO → Missed opportunity
```

## Rules

**Always:**
- Build a portfolio
- Diversify across verticals
- Stair-step into bigger deals
- Cross-pollinate partners

**Never:**
- Bet everything on one partner
- Skip testing smaller partners
- Overpay too early
- Ignore portfolio balance

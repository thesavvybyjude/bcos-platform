# Whitelisting.md

## Purpose
To provide frameworks for whitelisting partner content.

## Core Philosophy
**Ads perform better when they come from the actual person.**

- People trust personal accounts more than brand accounts
- Partner content feels more real
- Whitelisting creates full-funnel integration
- Partners get exposure and a share of spend

## Principles

### 1. Whitelist Everything
- Run ads from partner accounts
- Ad feels more authentic
- Higher engagement
- Better performance

### 2. Structure Win-Win
```
Partner Ad Structure:
  │
  ├─ Brand pays for ad spend
  ├─ Partner gets a portion of spend
  ├─ Partner's brand grows (followers)
  ├─ Brand gets high-performing ads
  └─ Both win
```

### 3. Full-Funnel Integration
- Podcast ad read → Top of funnel
- Social media clip → Mid-funnel
- Whitelisted ad → Late-funnel
- Website offers → Conversion
- Retargeting → Retention

## Process

### Whitelisting Workflow:
```
1. Create content with partner
2. Partner posts content to their account
3. Brand whitelists the content
4. Brand puts spend behind it
5. Partner gets a share of spend
6. Partner is incentivized to create more
7. Flywheel continues
```

## Decision Framework

```
Should I Whitelist This Content?
  │
  ├─ Is it coming from a trusted partner?
  │   ├─ YES → Whitelist
  │   └─ NO → Maybe brand account
  │
  ├─ Does it feel authentic?
  │   ├─ YES → Whitelist
  │   └─ NO → Don't run it
  │
  ├─ Is partner benefiting?
  │   ├─ YES → Good deal
  │   └─ NO → Need better structure
  │
  └─ Is it full-funnel?
      ├─ YES → Valuable
      └─ NO → Fill gaps
```

## Rules

**Always:**
- Whitelist partner content
- Structure win-win deals
- Integrate across funnel
- Incentivize partners

**Never:**
- Run brand-only ads exclusively
- Forget partner benefit
- Think short-term
- Ignore performance

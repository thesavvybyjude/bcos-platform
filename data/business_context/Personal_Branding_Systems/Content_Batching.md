# Content_Batching.md

## Purpose
To provide frameworks for batching content production.

## Core Philosophy
**Batch content = Freedom from the content hamster wheel.**

- Film 18 videos in 7 days
- 2 months of content in 1 week
- Lock in and create
- No daily content stress

## Principles

### 1. Batch Everything
```
7-Day Filming Week
  │
  ├─ 18 Long-Form Videos
  ├─ 15-20 Short-Form Videos
  ├─ 30-40 Ads
  └─ B-Roll
```

### 2. The Loom Pre-Brief
- Record a Loom for each topic
- 10-45 minutes of your authentic POV
- Producer turns it into brief
- When you film, you just turn on and go

### 3. Be a Diva
- Have everything ready before you film
- You shouldn't touch lighting, camera, etc.
- Briefs printed out beforehand
- Your job: show up and perform

### 4. Native Embeds
- Don't break the hypnosis
- Weave lead magnets into the conversation
- Set up the conversation so the lead magnet is the answer
- Example: Talk about editors → "Want my editors? Link below."
- Don't break away for non-native ads

## Process

### Content Batching Workflow:
```
1. Ideate topics (from customers, trends, books)
2. Record Loom for each topic (10-45 min)
3. Producer creates briefs
4. Schedule filming week (every 2 months)
5. Film 3-4 long-form per day
6. All lights, camera, audio ready
7. You just show up and go
8. Editor takes footage
9. 2 months of content done
```

### Native Embed Workflow:
```
1. Create content
2. Native embed lead magnet
3. Get email
4. Welcome sequence (5 days)
5. FOMO sequence (4 days)
6. Weekly newsletter
7. Offer sale
```

## Decision Framework

```
Should I Batch Content?
  │
  ├─ Do I dread daily content creation?
  │   ├─ YES → Batch
  │   └─ NO → Maybe you're a content machine
  │
  ├─ Do I have a team?
  │   ├─ YES → Batch
  │   └─ NO → Consider with small team
  │
  ├─ Am I consistent on content?
  │   ├─ YES → Continue
  │   └─ NO → Batch for consistency
  │
  └─ Do I want my time back?
      ├─ YES → Batch
      └─ NO → You're a masochist
```

## Rules

**Always:**
- Batch content
- Record Loom pre-briefs
- Have everything ready before filming
- Focus on play, not performance
- Native embed lead magnets
- Don't break the hypnosis

**Never:**
- Create content daily
- Film without pre-briefs
- Touch technical equipment
- View it as a chore
- Break away for non-native ads
- Forget to capture email

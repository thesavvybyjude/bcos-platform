# Content_Waterfall.md

## Purpose
To provide a framework for the content waterfall system.

## Core Philosophy
**One piece of long-form content = 24+ pieces of content across platforms.**

- Long-form is the source of all content
- Repurpose across platforms
- Don't create from scratch for every platform
- Work smarter, not harder

## Principles

### 1. The Content Waterfall
```
Long-Form Content (18-min YouTube)
  │
  ├─ 6 YouTube Shorts
  ├─ 6 Instagram Reels
  ├─ 6 TikTok Videos
  ├─ 6 X/Twitter Videos
  ├─ 10+ Tweets
  ├─ 2-3 LinkedIn Posts
  ├─ 1-2 Newsletters
  └─ 1 Transcript (for blog/seo)
```

### 2. Quality Over Quantity
- Focus on making one great piece
- Let the waterfall create the rest
- Don't try to be an engine
- Your job: create the source

### 3. Less But Better
- One core pillar per piece
- Remix in new ways
- Don't cover a thousand things
- Be known for one thing

### 4. Native Embeds
- Don't break the hypnosis
- Weave lead magnets into the conversation
- Set up the conversation so the lead magnet is the answer
- Example: Talk about editors → "Want my editors? Link below."
- Don't break away for non-native ads

## Process

### Content Waterfall Workflow:
```
1. Create one long-form piece (YouTube, Newsletter)
2. Extract key moments/clips
3. Repurpose to short-form (Reels, Shorts, TikTok)
4. Extract quotes for tweets
5. Rewrite for LinkedIn posts
6. Synthesize for newsletter
7. Post across platforms
```

### Native Embed Workflow:
```
1. Create content
2. Native embed lead magnet
3. Get email
4. Welcome sequence (5 days)
5. FOMO sequence (4 days)
6. Weekly newsletter
7. Offer sale
```

## Decision Framework

```
What Should Be My Pillar Content?
  │
  ├─ Where do I best express my genius?
  │   ├─ Video → YouTube
  │   ├─ Writing → Newsletter/X
  │   └─ Audio → Podcast
  │
  ├─ What format is most natural?
  │   ├─ Pen-first → Writing
  │   └─ Camera-first → Video
  │
  └─ Where is my audience?
      ├─ YouTube → Long-form video
      ├─ Twitter/X → Written threads
      └─ LinkedIn → Written posts
```

## Rules

**Always:**
- Create one long-form pillar
- Waterfall to every platform
- Don't create from scratch for each
- Remix and repurpose
- Native embed lead magnets
- Don't break the hypnosis

**Never:**
- Try to be an engine
- Create unique content for every platform
- Ignore long-form
- Forget the waterfall
- Break away for non-native ads
- Forget to capture email

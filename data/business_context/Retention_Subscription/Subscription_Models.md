# Subscription_Models.md

## Purpose
To provide frameworks for subscription model optimization.

## Core Philosophy
**Longer commitments = Better retention = Higher LTV.**

- 3-month subscriptions drive AOV
- 3 months gives product time to work
- 3 months = Habit formation
- AOV increased from $89 to $280

## Principles

### 1. The Three-Month Magic
- One-time: $112
- One-month: $89
- Three-month: $78/month ($235 upfront)
- 50%+ of customers choose 3-month

### 2. Why 3 Months Works
```
90 days = Product efficacy window
  │
  ├─ 95% noticed energy improvement
  ├─ 85% better gut health
  ├─ 80% slept better
  └─ 75% sharper cognitive performance
```

### 3. Benefits of 3-Month Commitments
- AOV: $89 → $280
- Better unit economics (shipping savings)
- Habit formation
- Customer saves money
- Company saves on logistics

## Decision Framework

```
What Subscription Length?
  │
  ├─ Does product need time to work?
  │   ├─ YES → 3-month is best
  │   └─ NO → 1-month works
  │
  ├─ Do I want higher AOV?
  │   ├─ YES → 3-month
  │   └─ NO → 1-month
  │
  ├─ Do I want better retention?
  │   ├─ YES → 3-month (habit formation)
  │   └─ NO → 1-month
  │
  └─ Is shipping expensive?
      ├─ YES → 3-month (save on logistics)
      └─ NO → 1-month
```

## Rules

**Always:**
- Offer multiple subscription options
- Discount for longer commitments
- 3-month is optimal for supplements
- Make it easy to choose

**Never:**
- Make subscriptions hard to cancel
- Ignore the efficacy window
- Underprice longer commitments
- Forget to communicate value

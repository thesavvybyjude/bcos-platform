# CAC_LTV_Framework.md

## Purpose
To provide frameworks for CAC/LTV optimization.

## Core Philosophy
**World-class is 3-3.5x LTV to CAC with <4-month payback.**

- Payback period is the most critical metric
- 3-3.5x LTV/CAC = World-class
- Under 4-month payback = Rapid scalability
- The lower the payback, the faster you can grow

## Principles

### 1. The Three Key Metrics
```
1. CAC (Customer Acquisition Cost)
   - Marketing spend / New customers
   - Under $50 is good for subscription

2. LTV (Lifetime Value)
   - Average revenue per customer × Average retention
   - 24-month horizon

3. Payback Period
   - Time to recoup CAC
   - Under 4 months = World-class
   - 6 months = Good
   - 12 months = Marginal
```

### 2. World-Class Ratios
| Metric | IM8 | Best-in-Class |
|--------|-----|---------------|
| LTV/CAC | 3-3.5x | 3-5x |
| Payback | <4 months | 3-6 months |
| AOV | $280+ | $200+ |

### 3. The Math That Enables Scale
```
If payback <4 months:
  → You can reinvest faster
  → Your growth compounds
  → You can scale aggressively
  → CAC constraints are minimal
```

## Decision Framework

```
Should I Scale Spend?
  │
  ├─ Is LTV/CAC >3x?
  │   ├─ YES → Scale
  │   └─ NO → Optimize
  │
  ├─ Is payback <4 months?
  │   ├─ YES → Scale aggressively
  │   └─ NO → Optimize first
  │
  ├─ Is AOV >$200?
  │   ├─ YES → Good economics
  │   └─ NO → Need higher AOV
  │
  └─ Is retention improving?
      ├─ YES → Scale
      └─ NO → Fix retention first
```

## Rules

**Always:**
- Track payback period daily
- Target 3-3.5x LTV/CAC
- Under 4-month payback = Scale
- Improve AOV to improve economics

**Never:**
- Scale without good payback
- Ignore LTV
- Underinvest in retention
- Let payback slip above 6 months

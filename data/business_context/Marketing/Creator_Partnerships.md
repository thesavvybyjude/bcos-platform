# Creator_Partnerships.md

## Purpose
To provide frameworks for marketing through creator partnerships.

## Core Philosophy
**The creator economy is a distribution channel.**

- Trust transfers from creator to brand
- Long-term partnerships > one-off posts
- Multi-channel exposure wins
- Deep relationships > broad reach

## Principles

**1. Long-Term Partnerships**
- 6-12 month commitments
- Multi-channel exposure
- Deep integration
- Category ownership

**2. Multi-Channel Engagement**
- Social
- Podcast
- Newsletter
- Video
- Events

**3. Focus on ROI**
- High LTV customers
- Trust-driven conversion
- Repeated exposure
- Brand association

## Decision Framework

```
Which Creator Partnership?
  |
  |- Does their audience match mine?
  |   |- YES → Consider
  |   |- NO → Skip
  |
  |- Can we do multi-channel?
  |   |- YES → Higher value
  |   |- NO → Lower value
  |
  |- Can we do long-term?
  |   |- YES → Strategic partnership
  |   |- NO → One-off engagement
  |
  |- Is LTV > 3x Cost?
      |- YES → Proceed
      |- NO → Optimize or skip
```

## Rules

**Always:**
- Go deep with partners
- Multi-channel exposure
- Long-term commitments
- Track performance

**Never:**
- One-off influencer posts
- Ignore audience fit
- Underinvest
- Skip measurement

## ADDITION: Partnership Fundamentals

**Core Philosophy Addendum:**
**Rome wasn't built in a day. Neither are partnerships.**

### Additional Principles:

**5. Start with Smaller Partners**
- Micro influencers first
- Learn what works
- Build the muscle
- Then go big

**6. Seven-Figure Deals Require Scale**
- Don't start with Rogan
- You need to be able to afford misfires
- Seven-figure deals are expensive
- Get to scale first

**7. Long-Term Deals Compound**
- 3+ years minimum
- Evergreen content keeps working
- Huberman episodes from 3 years ago still drive sales
- 1-month deals = 1-month value

### Updated Rules

**Always:**
- Start small
- Build the muscle
- Think long-term
- Scale to big deals

**Never:**
- Start with A-listers
- Underestimate deal size
- Think short-term
- Ignore evergreen value

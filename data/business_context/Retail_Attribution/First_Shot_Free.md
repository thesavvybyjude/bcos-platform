# First_Shot_Free.md

## Purpose
To provide frameworks for retail attribution through QR codes.

## Core Philosophy
**Sampling at scale creates attribution in a black box.**

- Retail attribution is notoriously hard
- QR code on product solves attribution
- Always-on sampling creates data
- Every phone number = Future remarketing

## Principles

### 1. The QR Code Hack
```
Customer buys product at Target
  │
  ├─ Scans QR code on bottle
  ├─ Uploads photo of receipt
  ├─ Gets reimbursed (Venmo/PayPal)
  ├─ Provides phone number
  └─ Brand now has attribution and data
```

### 2. Always-On Sampling
- No need for in-store demos
- No co-op marketing required
- Every purchase is a data point
- Every purchase is a future marketing opportunity

### 3. Expensive But Worth It
```
Cost: Full retail price reimbursed ($4.95)
  │
  ├─ But: Always-on sampling
  ├─ But: First-party data capture
  ├─ But: Attribution clarity
  ├─ But: Remarketing opportunities
  └─ More than pays for itself
```

## Process

### First Shot Free Workflow:
```
1. Product on shelf with QR code
2. Customer buys product (full price)
3. Scans QR code
4. Uploads receipt photo
5. Gets Venmo/PayPal refund
6. Brand captures phone number
7. Brand has attribution data
8. Brand can remarket via SMS
```

## Decision Framework

```
Should I Implement First Shot Free?
  │
  ├─ Is my product in retail?
  │   ├─ YES → Consider
  │   └─ NO → Not applicable
  │
  ├─ Can I afford the reimbursement?
  │   ├─ YES → Proceed
  │   └─ NO → Need better economics first
  │
  ├─ Do I have high LTV?
  │   ├─ YES → Pays for itself
  │   └─ NO → Might not be worth it
  │
  └─ Is attribution valuable?
      ├─ YES → Do it
      └─ NO → Skip
```

## Rules

**Always:**
- Put QR codes on packaging
- Capture phone numbers
- Use for attribution data
- Remarket to customers

**Never:**
- Underestimate data value
- Ignore attribution
- Let data go unused
- Make the process hard

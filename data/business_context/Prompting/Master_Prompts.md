# Master_Prompts.md

## Purpose
To provide a framework for creating master prompts.

## Core Philosophy
**A master prompt is the AI equivalent of a team member who's known you for 5 years.**

- Document your full context
- Update every 6 weeks
- Upload to any AI tool
- Now any AI knows you intimately

## Principles

### 1. What Is a Master Prompt?
- A document with your full context
- Who you are, what you do, your goals
- Your business, team, revenue, strategy
- Personal life, preferences, relationships

### 2. How to Create a Master Prompt
```
1. Open AI tool (Claude preferred)
2. Say: "I want to create a master prompt for my role. Ask me questions to get it."
3. Answer questions (use Whisper Flow)
4. AI creates the master prompt
5. Save as PDF
6. Upload to any new AI tool
```

### 3. Update Every 6 Weeks
- Life changes fast
- Businesses pivot
- New team members
- New goals

### 4. Reference Other Systems
- Link to Notion documents
- Link to SOPs/playbooks
- Link to strategy documents
- Master prompt = Gateway to all systems

## Process

### Master Prompt Creation:
```
1. Open Claude
2. "Create a master prompt for my role. Ask me questions."
3. Answer 20-30 questions
4. AI creates 10-20 page document
5. Review and refine
6. Save as PDF
7. Upload to any AI tool
8. Update every 6 weeks
9. Watch outputs improve 10x
```

## Decision Framework

```
What Should Be in My Master Prompt?
  │
  ├─ Business context
  │   ├─ Company mission
  │   ├─ Revenue
  │   ├─ Team structure
  │   ├─ Strategic planning
  │
  ├─ Personal context
  │   ├─ Goals
  │   ├─ Relationships
  │   ├─ Fitness
  │   ├─ Money
  │
  ├─ Role context
  │   ├─ What you're responsible for
  │   ├─ How you operate
  │   ├─ Your principles
  │
  └─ Systems context
      ├─ SOPs
      ├─ Playbooks
      ├─ Notion databases
```

## Rules

**Always:**
- Have a master prompt
- Update every 6 weeks
- Upload to every new AI tool
- Answer questions with Whisper Flow

**Never:**
- Skip creating a master prompt
- Let it get stale
- Underestimate its power
- Use generic prompts without context

# System_Prompts.md

## Purpose
To provide a framework for system prompts.

## Core Philosophy
**System prompts tell the AI how to think.**

- Different from master prompts (context)
- Tell the AI its role and constraints
- Study the best system prompts (GitHub)
- Most people ignore this entirely

## Principles

### 1. What Is a System Prompt?
- Tells the AI its role
- "Act like a world-class app developer"
- Defines constraints and rules
- Shapes the AI's thinking

### 2. The Four-Part Prompt Structure
```
1. Role
   → "Act like a world-class developer"
   → "Think like a Harvard MBA"

2. Outcome
   → What you want accomplished
   → Be specific

3. Data
   → What the AI needs to know
   → Upload files, copy-paste content

4. Format
   → How you want the output
   → "Visualize this"
   → "JSON format"
   → "Mobile-optimized web page"
```

### 3. Study the Best System Prompts
- GitHub search: "system prompts for top AI tools"
- 27 system prompts from top companies released
- Notion AI, Lovable.dev, etc.
- 100% utilization of character limits
- This is the art of prompting

## Process

### System Prompt Creation:
```
1. Define the role
   "Act like a world-class [X]"

2. Define the outcome
   "I need a [specific deliverable]"

3. Provide the data
   Upload files, copy-paste content

4. Specify the format
   "Output as spreadsheet"
   "Visualize this"
   "JSON format"

5. Let AI create
   One-shot, boom, boom output
```

## Decision Framework

```
How to Structure a Prompt:
  │
  ├─ Role → Who is the AI being?
  │   ├─ World-class developer
  │   ├─ Marketing expert
  │   ├─ Financial analyst
  │
  ├─ Outcome → What do you need?
  │   ├─ App, dashboard, document
  │   ├─ Strategy, plan, analysis
  │
  ├─ Data → What does AI need?
  │   ├─ Files, URLs, context
  │   ├─ Customer data, financials
  │
  └─ Format → How should it be delivered?
      ├─ Visual, spreadsheet, JSON
      ├─ Web page, document
```

## Rules

**Always:**
- Use the four-part structure
- Study best system prompts
- Give AI a role
- Specify the format

**Never:**
- Use vague prompts
- Forget the role
- Ignore format
- Underestimate system prompts

# Remote_Work.md

## Purpose
To provide frameworks for scaling a fully remote company.

## Core Philosophy
**Remote work is a talent acquisition strategy, not a perk.**

- Access to global talent
- Cost efficiencies
- Retention advantages
- Lifestyle benefits

## Principles

**1. Hire for Talent, Not Location**
- Best person for job anywhere
- Global talent pool
- Diversity of thought
- No geographic limits

**2. Focus on Outcomes, Not Hours**
- Ship features or don't
- Hit quota or don't
- Clear deliverables
- High trust environment

**3. Overcommunicate**
- Weekly success lists
- Sunday emails
- Monday all-hands
- Friday all-hands

## Process

**Remote Operating Rhythm:**
```
Sunday:
  - CEO sends weekly update
  - Every team submits priorities

Monday:
  - All-hands (40 minutes)
  - Review weekly success list

Daily:
  - Slack communication
  - Asynchronous collaboration

Friday:
  - All-hands
  - Review priorities
  - Accountability check
```

## Decision Tree

```
Should Our Company Be Remote?
  |
  |- Can I hire top talent remotely?
  |   |- YES → Remote is viable
  |   |- NO → Consider hybrid
  |
  |- Is this culturally acceptable?
  |   |- YES → Remote works
  |   |- NO → Need office
  |
  |- Can we overcommunicate?
  |   |- YES → Remote works
  |   |- NO → Need in-person
  |
  |- Are we outcome-focused?
      |- YES → Remote works
      |- NO → Need oversight
```

## Rules

**Always:**
- Hire A players
- Focus on outcomes
- Overcommunicate
- Build high trust

**Never:**
- Micromanage
- Be location-dependent
- Underinvest in communication
- Ignore culture

## AI Instructions

When implementing remote work:
- Create communication rhythms
- Track outcomes vs. inputs
- Build accountability systems
- Foster culture intentionally
- Document everything
